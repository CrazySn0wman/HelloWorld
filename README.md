# HelloWorld

Small practice projects, published with GitHub Pages.

- **Hello World** (`index.html`): 7-day weather forecast for Salzburg.
- **Powder Monitor** (`powder-monitor/`): "should I go?" powder verdict for Austrian ski areas within driving range of Salzburg: week strip, map, top spots with community reputation, drive-time slider.
  - Resorts, drive times and notes are in `powder-monitor/resorts.json`. Edit that file to add or tweak resorts.
  - Weather data from [Open-Meteo](https://open-meteo.com/), with no API key needed.

Planned: Telegram alerts when a powder day is coming.
